# Support registry conversion: findings

Defects and open questions found while converting the support system to derive
from `src/supports/supportTypeRegistry.ts`. Each was a hand-written type list
that disagreed with the registry.

Referenced from `backlog.md`, which carries the broad rules. This file is the
detail: one row per finding, kept because the same shape recurs.

**Status values.** `fixed` needs no action. `open` is a live decision or a
defect nobody has taken. `recheck` is a change that tests clean but alters
visible behaviour, so it wants a second pair of eyes.

Some rows predate the current code and may be stale; verify before acting on
one. Move a row here to `backlog.md` only if it becomes a rule to follow.
